# html-sandbox/ts

A scratch directory for periodically writing a plain, straightforward
implementation of the blog — most recently TypeScript +
[Hono](https://hono.dev/) on Cloudflare Workers, with no Wasm — to see how
much the Go and MoonBit builds pay for their approach.

Because there is little value in maintaining it continuously, everything
here is deleted from time to time. To rerun the experiment, rebuild it
from scratch. Related sketch notes:
[docs/sketch/ja/ts-hono-workers.md](../docs/sketch/ja/ts-hono-workers.md).
