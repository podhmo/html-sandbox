# Claude Code から: 余談 — 考える役と清書する役がいるとき、清書をどう頼むか

執筆: Claude Code（Opus 5.5）。README と 01、02 を書いたのと同じセッションで、依頼した人に頼まれて書いた。

README と 01、02 ができたあと、依頼した人はこのバンドルを別のエージェントに渡して、日本語として自然な文章に直させた。渡したのは次の一文だけで、何をするかははっきりしているが、どう直すかはほぼ任されている。

> git diffなどで確認して現在書かれた記事を把握し。その記事全体を日本語として自然な文章に直してほしい。

返ってきた差分は、文としては滑らかになっていたが、文末が「〜のである」の論説調に揃い、元の文になかった評価の言葉が足されていた。01 には「わざわざ」「安易に」「無批判に」「まったく同じ失敗のパターンを繰り返していた」が入り、README には「本末転倒である」「真の比較」「鮮明に現れた」が入った。どれも issue #133 が避けたいとしていた、鋭さを見せる書き方や、反省で締める書き方の側の言葉だった。

意味が変わったところもあった。依頼した人の「ペダンティックにならなければよいが」という懸念が「なりすぎなければよい、という整理になった」と許容と決定事項に変わり、かぎ括弧で引いた Codex の比較の一文には原文にない言葉が足された。「一本の筋」は「一本の論理的な筋道」になったが、元の対話で依頼した人は「論理的に述べるのではなく」と言っていて、この記事は時間ではなく原因でつなぐことを「論理」と呼ばないようにしてきた。01 の「+α は書かなくて良い」は「+α の推測は書かなくてよい」になったが、+α は推測ではなく、そのときの取捨選択や詳しい文脈のことだった。

こうなったのは、清書したエージェントの手元に、この記事が何を守って書かれてきたかがなかったからだと思う。「自然な文章」の基準を、一般的に整った日本語、つまり論説文の側に置けば、主語を補い、言い切りを強め、評価で段落を締めるのは自然な直し方になる。ところが、この記事で守ってきたもの（引用は原文のまま、誰が言ったかを消さない、「論理」と「因果」を分ける、常体で淡々と書く）は、どれも言い換えると滑らかに見える種類のものだった。

依頼した人は、この差分に対する指摘を自分に書かせ、それを清書したエージェントに返した。二回目の差分は README の 2 か所だけになり、元の文に戻したうえで、冒頭の一文に統合の記事も含むことを足し、三者の書き直しを一段落ずつに分けていた。指摘の一覧が、清書に必要な文脈の代わりになったことになる。ただ、その指摘は一回目の差分を見てから書けたもので、最初の依頼には入れようがなかった。

そこで、最初から清書を頼むならどう書くかを聞かれて、次のプロンプトを答えた。考えて書いた側が持っている文脈のうち、清書に効くもの（「自然」の基準、変えてはいけないもの、足してはいけないもの）を先に渡し、変えた文ごとに元の文と並べさせて、意味のずれを後から確かめられるようにしている。

```
slops/2026-11-07-investigation-note-skill.md/ の README.md、01-why-this-shape.md、
02-prompt-in-hindsight.md を、日本語として読みにくいところだけ直してほしい。
まず issue #133 を読むこと。この記事は、そこで避けたいとされた書き方
（視点の鋭さのアピール、テーマを決めて主張すること、反省で締めること）を
しないように書き直してきたもので、「自然な文章」はその範囲で考える。

直すもの:
- 主語や係り受けが追いにくい文、一文が長すぎて読み返しが要る文
- 訳文のように硬い言い回し（意味を変えずに言い換えられるもの）

変えないもの:
- 意味と事実。言い換えで範囲や強さが変わるなら、元のままにする
  （「ならなければよい」を「なりすぎなければよい」にしない、など）
- かぎ括弧の中の引用。原文のまま
- 誰が言ったか、誰が決めたか。受け身にして主体を消さない
- 「論理」と「因果」、「文体」と「何を語るか」のように、
  記事の中で区別している言葉
- 常体の文末（〜した、〜だった）。「〜のである」の論説調にしない

足さないもの:
- 元の文にない評価や強調（機械的に、安易に、真の、鮮明に、本末転倒、など）
- 自分を責める言い回しや、書き手・依頼した人への評価

直したあと、変えた文ごとに元の文と並べ、何が読みにくかったかを一行で添えてほしい。
読みにくくない文は直さなくてよい。
```

これでうまくいくかは分からない。試していないし、「変えないもの」の例は、今回の一回目の差分で崩れたところから拾っている。別の記事では、別のところが崩れるかもしれない。

考える役と清書する役を分けるやり方には、少なくとも二つの形がある。考えた側が守るものを先にプロンプトへ書く形と、清書させてから考えた側が差分を読んで指摘を返す形で、今回実際に起きたのは後者だった。前者は守るものを事前に言葉にできるときに使えて、後者は一回の往復が増える代わりに、言葉にしていなかったものが差分で見つかる。どちらがよいかは、比べていないので分からない。
