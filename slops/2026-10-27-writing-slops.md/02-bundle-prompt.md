# slops の記事バンドルの作成依頼

html-sandbox の `slops` に、次のテーマで日本語の記事を作ってください。

- テーマ: （ここに書く）
- 日付: （記事の日付。指定しない場合は Asia/Tokyo の今日）
- スラッグ: （小文字の英字・数字・ハイフンで書く）
- 参照する材料と、本文の外に分けて残したい補足: （ここに書く）

まずリポジトリの `AGENTS.md` と `.claude/skills/write-slops/SKILL.md` を読んでください。

`slops/YYYY-MM-DD-slug.md/` というディレクトリを一つの記事にしてください。`README.md` を記事の顔とし、補足や別の説明を必要に応じて `01-notes.md` などに分けてください。複数のファイルを一つの Markdown ファイルに連結して保存しないでください。役割のないファイルは作らなくて構いません。

顔となる `README.md` にはタイトルを付けてください。front matter を使うなら `title`、`description`、`prev`、`next` 以外のキーは追加しないでください。残りのファイルは名前順で並ぶので、表示順が必要なら数字の接頭辞を付けてください。サブディレクトリやバイナリー画像は置かないでください。

SVG の図を本文へ入れる場合は、開始フェンスをバッククォート三つと小文字の `svg` にしてください。言語指定のないフェンスでは図がコードとして表示されます。SVG は簡単な図形とテキストで作り、フォントデータや外部フォントは持ち込まないでください。必要なら `.svg` を独立したメンバーとして置くこともできます。Markdown の画像記法は使わないでください。

相対リンクは、そのリンクを書くファイルの場所を基準にしてください。同じページ内の補足セクションへ飛ばしたいリンクと、メンバーの原文ファイルへのリンクを区別してください。

本文で使う記法や図の表示は、一文書ずつ `/preview` で確認できます。ただしプレビューはバンドルを組み立てず、相対リンクも `posts/preview.md` を基準に解決します。ファイルの並び、メンバーの取得、バンドル内のリンクは、ローカルのブログでも確認してください。確認した範囲を報告してください。
