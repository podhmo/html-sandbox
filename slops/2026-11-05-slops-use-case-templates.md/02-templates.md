# 目的ごとの依頼テンプレート

[バンドル用プロンプト](../2026-10-27-writing-slops.md/02-bundle-prompt.md) の「テーマ」の行を、下のどれか一つで置き換えて使う。記法・置き方・確認の決まりはそのプロンプトと SKILL.md のまま。

どのテンプレートにも、語り手・文体・調子・感想についての項目はない。書いていない項目は書き手に任せる。direction の行は既定値で、依頼する人が書き換えてよい。

## 共通の項目

```
目的: （下の 8 つから一つ）
発端: （issue、PR、発言へのリンク）
材料: （読むもの、使うデータ、触ってよい範囲）
フォーカス: （読み手が持ち帰るもの。1〜3 点）
direction: （中身の重みをどちらに置くか）
入れないもの: （扱わない話題、docs/sketch や別の記事に回すもの）
補足に分けるもの: （一覧、原文、AI が書いた文献メモなど）
```

## 変更の報告

```
目的: 変更の報告
発端:
材料: 変更の PR と diff
フォーカス:
- サイトや道具の何が変わったか
- 決めたことと、見送った案
- どう確かめたか、何がまだ確かめられていないか
direction: 作った順ではなく、決めた順に。見送った案とその理由を残す
入れないもの: 実装手順の再現に必要な細部（docs/ に置く）
補足に分けるもの:
```

## 詰まった経緯

```
目的: 詰まった経緯
発端:
材料: エラー、ログ、直した PR
フォーカス:
- 何が起き、どう気づいたか
- 原因（分かった範囲と、推測の範囲）
- どう直したか、または直さずに止めた理由
direction: 原因に辿り着くまでの外れた仮説も残す
入れないもの:
補足に分けるもの: 長いログ
```

## 実験・比較

```
目的: 実験・比較
発端:
材料: 試したもの、出力、比べた条件
フォーカス:
- 何を確かめるために試したか
- 何が出たか（出力そのものを見せる）
- 何が駄目だったか、何を試していないか
direction: 失敗した試行も結果に含める。比べた条件をそろえて書く
入れないもの: 試していない案の評価
補足に分けるもの: 全出力、生成コードの所在
```

## 実現性の調査

```
目的: 実現性の調査
発端:
材料: 調べた文献、見積もり、試した範囲
フォーカス:
- 実現したいこと
- 実現を阻むものがどこにあるか
- 次に何が決まれば進めるか
direction: 調べた事実と手順は docs/sketch に置き、記事は調べた結果どこで止まったかに寄せる
入れないもの: 手順書としての詳細
補足に分けるもの: AI が書いた文献メモ（読んだ範囲を項目ごとに書く）
```

## 他人の成果物を読む

```
目的: 他人の成果物を読む
発端:
材料: 対象のリポジトリや文書。読んだ範囲
フォーカス:
- それが何か
- 何を確かめようとしているように見えるか（推測と、その根拠）
- 確かめられなかったこと
direction: 推測には必ず根拠の箇所を添える。作者の意図を断定しない
入れないもの: 対象の良し悪しの評価
補足に分けるもの: 作者からの回答があれば追記として
```

## 任せた作業の記録

```
目的: 任せた作業の記録
発端:
材料: 任せた作業の PR、セッションの記録
フォーカス:
- 誰（どのエージェント、どのモデル）に何を任せたか
- どこで人が入ったか、何を差し戻したか
- 何をもって受け入れたか
direction: 起きた順に。エージェントの性質の一般化は、この記録から言える範囲にとどめる
入れないもの:
補足に分けるもの: やりとりの抜粋
```

## 主張の検討

```
目的: 主張の検討
発端: （主張した人と、その発言）
材料: 主張を支える、または崩す事例
フォーカス:
- 主張の中身
- どの事例がどの部分を支え、どの部分は支えないか
- 確かめていない部分
direction: 判定より、判定に使った事例を多く。事例のない一般化はしない
入れないもの: 主張した人への評価
補足に分けるもの: 事例の一覧
```

## 書き方そのもの

```
目的: 書き方そのもの
発端:
材料: SKILL.md、プロンプト、対象の記事
フォーカス:
- どの決まりを見たか、変えたか
- その決まりが記事にどう効いていたか（記事のどこに出ているか）
direction: 適用した変更と、候補にとどめた変更を分ける
入れないもの: 既存記事の書き直し
補足に分けるもの: 決まりの一覧
```

記法の見本は、記法を足したときの確認用で、依頼の形にする必要がないので外した。
