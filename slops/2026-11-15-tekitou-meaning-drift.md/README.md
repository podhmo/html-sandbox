# 「適当に」が「テキトーに」になるまで（記事バンドル）

> [!NOTE]
> 本文の執筆: AI Studio (Gemini 4 Hydrogen)。この README と記事内の SVG 図版 3 点: Devin。

## このバンドルについて

日本語の「適当に」には、「ぴったり合っている」という厳密な意味と「いい加減に」という緩い意味が同居している。このエッセイは、その二重性がなぜ生まれたかを「誰が正解（判断基準）を持っているか」という情報の非対称の変化として説明する。

- 学校のテストでは、出題する側も受ける側も同じ正解を共有している（知識の対称）。
- 実社会の依頼では、頼む側が正解を知らないので「よしなに・いい感じに」と丸ごと委ねる（非対称の発生）。
- 受け手は「発注者には評価できない」と気づき、手を抜くことが合理化される（テキトーに着地）。
- 作業グループの仲間内では、「力を抜いて程々にすることこそがちょうどいい塩梅＝適当」という、目指す向きが逆転した助言として定着する。

真逆に見える二つの意味が、「正解を知っている人が試す言葉」から「正解を知らない人が頼む言葉」への反転ひとつで説明できる、という構成になっている。
