# gratui — 設計書（ラフ版）

ターミナル上で有向グラフをASCIIアートっぽく可視化するCLIツール。
Go製・標準ライブラリのみ・`go build`で単一バイナリにビルドできること。

## 動機

dot/graphvizを入れずに、エッジリストをポンポン流して雑にグラフの形を
確認したい。ターミナルだけで完結するのが嬉しい。

## 入力

エッジリスト形式のテキスト。1行1エッジ。

```
A -> B
B -> C
A -> C
C -> D
```

- 区切りは `->`（前後の空白はあってもなくてもよい）
- `#` 始まりの行はコメントとして無視。空行も無視
- 入力元: 引数のファイルパス。引数が無い or `-` のときは標準入力
- 同じエッジの重複は1つにまとめる。ノード名は空白以外の文字列なら何でもよい
  （例: `api-server`, `db_01`, `ユーザー`）

## 出力（レイアウト）

層別（layered）レイアウトで左から右に描画する。

- トポロジカルソートで各ノードを「層」（= 任意の祖先からの最長距離）に割り当て、
  層ごとに縦にノードを並べる
- ノードは `[名前]` の形式で描く
- エッジは `──▶` など罫線・矢印系の文字を使ってそれっぽく引く。
  隣接層間は直線または斜め線でつなぐ。細部は実装に任せる（見た目が
  分かればよい）
- サイクルがある場合はトポロジカルソートができないので、検出したら
  先頭行に `cycle detected: ...` と警告を出し、入力順の層割りで
  それっぽく描く（落ちないことが大事）
- 孤立ノード（エッジの無いノード）は最終層の右にまとめてもよい

### 出力イメージ（この通りでなくてよい）

```
[A] ──▶ [B] ──▶ [C] ──▶ [D]
 ╲           ╱
  ╲─────────▶
```

## オプション

- `gratui [file]` — ファイル or 標準入力
- `--vertical` — 上から下に流れる縦レイアウト（余力があれば）
- `--version` — バージョン表示
- `-h` / `--help` — 使い方

## 実装メモ（ヒント）

- `go.mod` は `module gratui` で。main + 1〜2ファイル程度の小ささで
- パース → グラフ構築（隣接リスト＋入次数）→ Kahn法で層割り → 描画、の流れ
- 描画はキャンバス（2次元のrune配列）に文字を置いていって最後に
  行ごと出力すると楽
- テストは `main_test.go` にパースと層割りの分を少しだけ

## 非目標

- 色つけ、インタラクティブ操作、マウス対応
- 交差する辺のきれいなルーティング（それっぽければOK）
- DOT言語の完全互換
